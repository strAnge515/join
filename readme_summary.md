# Join 360

A Kanban project management tool built with HTML, CSS, JASON, Firebase and JavaScript.

---

## Features

- Task management
- Drag & Drop board
- Contact management
- Responsive design
- Mobile navigation
- Dynamic summary dashboard

---

## Project Structure

### /pages
Contains all HTML pages.

### /scripts
Contains JavaScript logic and functionality.

### /styles
Contains all CSS files including responsive layouts.

### /assets
Contains images, icons and fonts.

---

## Main Modules

### summary.js
Handles:
- Task summary counts
- Greeting system
- Urgent deadline display
- Mobile greeting animation

### board.js
Handles:
- Drag & Drop
- Task rendering
- Task movement

### contacts.js
Handles:
- Contact rendering
- Add/Edit/Delete contacts

---

## Responsive Design

The application is optimized for:
