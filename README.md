# Join – Team Task Management

## About the Project

Join is a web-based task and project management application designed to improve collaboration and organization within teams. The project was developed as a group assignment during a vocational training program by a team of four members.

By combining a dashboard, contact management, and a Kanban board, Join enables users to efficiently create, assign, organize, and track tasks throughout different stages of a project.

---

## Project Goal

The main objective of Join is to improve teamwork and workflow management. Tasks can be created, prioritized, assigned to team members, and monitored throughout their lifecycle.

The application helps teams stay organized, maintain transparency, and keep track of project progress at all times.

---

## Features

### User Management

- User registration
- Secure login functionality
- Personalized user dashboard

### Dashboard

- Overview of current tasks
- Display of key metrics and information
- Quick access to important project data

### Task Management

- Create tasks
- Edit tasks
- Delete tasks
- Set task priorities (Low, Medium, Urgent)
- Manage due dates
- Assign categories to tasks

### Kanban Board

- Clear visualization of all tasks
- Management of different workflow stages
- Organized project tracking

### Contact Management

- Add contacts
- Edit contacts
- Delete contacts
- Assign tasks to contacts
